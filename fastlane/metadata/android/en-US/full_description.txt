Wcash Wallet uses the original mobile interface adapted for Wcash Testnet and local Regtest. TWC test funds have no monetary value.

What can you do with Wcash Wallet?
* Create or restore a 24-word wallet.
* Synchronize with a Wcash lightwallet endpoint.
* Receive and send TWC using Ironwood addresses.
* Add addresses to your address book and save them as contacts.
* Review confirmed transaction history.

Wcash Mainnet is not enabled in this test build.
