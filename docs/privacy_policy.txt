Wcash Wallet Privacy Notice

Wcash Wallet is a self-custody wallet. The recovery phrase and wallet database
are stored on the device through the operating system's protected storage. The
Wcash Wallet project does not receive or retain a copy of the recovery phrase.

The wallet connects to the Wcash server selected in the application to
synchronize balances and transaction history and to broadcast transactions.
That server can observe network metadata such as an IP address, request timing,
and the chain data requested by the wallet. The local Regtest build connects
only to http://127.0.0.1:48234.

Wcash transactions can contain a memo supplied by the sender. A memo is part of
the transaction's private payload and can be recovered by a wallet that can
decrypt the corresponding output. Do not place recovery phrases, private keys,
passwords, or other secrets in a transaction memo.

The application does not add an analytics or advertising service. Information
the user deliberately shares through the operating system, a support link, or a
public issue tracker is governed by that service's own privacy terms.

Protect the recovery phrase. Anyone who obtains it can control the wallet and
recover its transaction data.
